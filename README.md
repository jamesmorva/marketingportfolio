# James Michael Morva Jr — Marketing Portfolio

Digital marketer and creative video producer specializing in high-retention short-form video campaigns, e-commerce arbitrage modeling, and campus governance leadership.

## Project Structure

- `src/components/Hero.tsx`: Kinetic display typography, scroll-linked branding, and primary CTAs.
- `src/components/VideoShowcase.tsx`: Live Bun & Mi Vietnamese restaurant commercial Instagram Reel embed with responsive mobile mockup.
- `src/components/ProjectsGrid.tsx`: Operational case studies (Bun & Mi, Textbook Arbitrage, Academic Senate Leadership).
- `src/components/ExperienceTimeline.tsx`: Balanced Target guest operations and core creative video production stack.
- `src/components/EducationCards.tsx`: Chapman University B.S. in Business Administration (Marketing & Finance) and academic honors.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS
- **Animations**: Motion (`motion/react`)
- **Icons**: Lucide React
